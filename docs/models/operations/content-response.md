# ContentResponse

Potentially modified content.

## Example Usage

```typescript
import { ContentResponse } from "@moderation-api/sdk/models/operations";

let value: ContentResponse = {
  id: "<id>",
  masked: true,
  unicodeCleaned: false,
  modified: "<value>",
};
```
