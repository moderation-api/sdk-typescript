# Actions

## Overview

### Available Operations

* [list](#list) - List moderation actions
* [create](#create) - Create an action
* [retrieve](#retrieve) - Get an action
* [update](#update) - Update an action
* [delete](#delete) - Delete an action
* [execute](#execute) - Execute moderation action

## list

List the moderation actions of the project. The list is paginated.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="listActions" method="get" path="/actions" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.actions.list();

  for await (const page of result) {
    console.log(page);
  }
}

run();
```

## create

Create an action.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="createAction" method="post" path="/actions" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.actions.create({
    key: "suspend-24h",
    name: "Suspend for 24 hours",
    type: "AUTHOR_BLOCK_TEMP",
    queueBehaviour: "REMOVE",
  });

  console.log(result);
}

run();
```
