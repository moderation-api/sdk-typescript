# Projects.ApiKeys

## Overview

### Available Operations

* [create](#create) - Create a project API key

## create

Create a new secret API key for a project and return it. Give each app or computer its own key, so you can revoke one without breaking the others. The project's existing keys keep working. Needs the `projects:write` permission.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="createProjectApiKey" method="post" path="/projects/{id}/api-keys" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.projects.apiKeys.create("<id>", {});

  console.log(result);
}

run();
```

import { ModerationApiCore } from "@moderation-api/sdk/core.js";

// Use `ModerationApiCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.

  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

  const res = await projectsApiKeysCreate(moderationApi, "<id>", {});
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {

  }
}

run();
