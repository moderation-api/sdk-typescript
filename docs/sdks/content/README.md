# Content

## Overview

### Available Operations

* [reject](#reject) - Reject content
* [allow](#allow) - Allow content
* [submit](#submit) - Submit content

## reject

Reject a content item with the built-in reject action, and resolve it in the review queue.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="rejectContent" method="post" path="/content/{id}/reject" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.content.reject("<id>", {
    reason: "Spam",
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript

import { contentReject } from "@moderation-api/sdk/funcs/content-reject.js";

// Use `ModerationApiCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const moderationApi = new ModerationApiCore({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const res = await contentReject(moderationApi, "<id>", {
    reason: "Spam",
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("contentReject failed:", res.error);
  }
}

run();
```

## submit

Submit content

### Example Usage

<!-- UsageSnippet language="typescript" operationID="submitContent" method="post" path="/moderate" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.content.submit({
    content: {
      type: "text",
      text: "Hey, check out my profile for a deal!",
    },
    contentId: "message-48213",
    authorId: "user-1092",
    conversationId: "room-general",
    metadata: {
      "platform": "ios",
    },
  });

  console.log(result);
}

run();
```
