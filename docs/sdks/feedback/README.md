# Feedback

## Overview

### Available Operations

* [create](#create) - Send feedback

## create

Sends a feature request, bug report or other feedback to the Moderation API team. The team reads every request and can reply by email. Limited to 5 requests per minute per organization.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="createFeedback" method="post" path="/feedback" -->
```typescript
import { ModerationApi } from "@moderation-api/sdk";

const moderationApi = new ModerationApi({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const result = await moderationApi.feedback.create({
    title: "Filter queue items by author trust level",
    description: "We review queue items by hand. We want to see items from new authors first, so we need a filter for trust level on the queue items list.",
    source: "mcp",
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { ModerationApiCore } from "@moderation-api/sdk/core.js";
import { feedbackCreate } from "@moderation-api/sdk/funcs/feedback-create.js";

// Use `ModerationApiCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const moderationApi = new ModerationApiCore({
  secretKey: process.env["MODAPI_SECRET_KEY"] ?? "",
});

async function run() {
  const res = await feedbackCreate(moderationApi, {
    title: "Filter queue items by author trust level",
    description: "We review queue items by hand. We want to see items from new authors first, so we need a filter for trust level on the queue items list.",
    source: "mcp",
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("feedbackCreate failed:", res.error);
  }
}

run();
```
